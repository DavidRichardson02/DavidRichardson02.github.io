# David Richardson — Engineering Portfolio

Source for [davidrichardson02.github.io](https://davidrichardson02.github.io/), a static portfolio focused on FPGA/RTL development, embedded systems, instrumentation, scientific computing, and technical documentation.

## Pages

- `index.html` — portfolio overview, selected work, capabilities, documents, and contact information.
- `projects.html` — evidence-conscious engineering case studies and current verification boundaries.
- `style.css` — responsive dark theme, accessibility states, reduced-motion behavior, and print rules.

## Project-status policy

The site distinguishes repository implementation, focused simulation, synthesis, implementation/timing closure, and physical bench evidence. A stronger level of validation is not inferred from a weaker one.

## Publishing

The repository is intentionally build-free. GitHub Pages serves the HTML and CSS directly from the default branch.
